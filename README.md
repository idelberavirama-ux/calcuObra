# CalcuObra - Aplicación Web Móvil Offline

## Descripción
Aplicación móvil desarrollada para el cálculo de materiales de construcción y presupuestos de obra en zonas remotas sin conexión a internet.

## Características
- Funcionamiento 100% Offline mediante almacenamiento local (LocalStorage).
- Módulos de cálculo técnico: Descapote con porcentaje de expansión, Muros y Mampostería.
- Gestión de proyectos (CRUD completo: Crear, Consultar, Editar y Eliminar).
- Generación y descarga de reportes de presupuesto en PDF.

## Tecnologías Utilizadas
- HTML5
- CSS3 (Diseño responsivo mobile-first)
- JavaScript (Vanilla - ES6)
- html2pdf.js
